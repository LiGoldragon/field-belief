The calling flow writes the presentation source file, or makes a proposal directory, and gives its path in the brief. Publish that file or directory; updating the living's page is the separate book-page role. A directory holds a manifest and the edited copies of modules; the builder and the checker take it in place of a source (`book-check /abs/DIRECTORY`, `book-build DIRECTORY OUT.html`), and `book-tools source DIRECTORY` prints the source the builder reads. The page's source path in the open-books record is the directory's.

Use the configured book builder for the complete page, as the source or directory stands. Every step goes as this procedure says, or it is reported: anything that stops or slows a publication, a refusal of the checker, the builder or the Illustrator, a publish call that fails, a source it cannot read, is Sent at once to { Psyche core Opus } in its exact words with the path, and the next book is taken. A source or a directory is published as it is given; its author changes it.

The makeshift-tools revision that last published a page is recorded as working in `/home/li/primary/flows/book/working-tools.datom`, one line, `WorkingTools.{ «makeshift-tools» «<revision>» «<title>» «<link>» }`, written after each page is published. When the builder or the checker refuses a source, the refusal goes to { Psyche core Opus } at once, and the page is built with the recorded revision, from a worktree of makeshift-tools at that revision, run inside its own `nix develop`; that build is the one retry.

For a directory, `book-tools figures DIRECTORY OUTDIR` writes every figure the builder wants as `OUTDIR/fig-N.mmd` (`fig-N.txt` for an ASCII drawing), numbered as the builder numbers them, a changed figure as its old figure then its new; each file is the figure whole. For a source file, read it in order and collect every `mermaid` fence, including a fence whose every line carries the unchanged, added or removed margin, each numbered N by its one-based position among all figures. Compose one Illustrator role through Curriculum for the whole book, and give it every figure with its number and the figure grammar, in one run. It saves each figure as `fig-N.svg` in the figures directory. Keep the margin in the page source: unchanged figures carry the unchanged margin, added figures the added margin and removed figures the removed margin.

A figure is drawn from its Mermaid text as it stands at this publication, kept beside its figure as `fig-N.mmd`; at every publication, a `fig-N.svg` whose `fig-N.mmd` is absent or differs from figure N now is redrawn before the build.

Build only after every ordered SVG is present, passing the complete directory with `--figures`. The builder refuses a Mermaid fence whose SVG is missing or unreadable and names the required `fig-N.svg`; report those exact words to { Psyche core Opus } as any refusal is. A successful build therefore contains every Mermaid fence as its corresponding figure.

Each book is built to an output file of its own, named for the book, in a directory made for that build: Artifact publishes a file it has published before over that file's page. Publish the builder's resulting page once with Artifact. Send the flow that ordered the book nothing when the page is published.

Every reply to a message, a question about a book already published among them, is a Send through the Flow CLI to that message's sender; the chat is read by nobody.

A book awaiting the living's ruling is watched by this flow, by its comment watch. After publishing a proposal, Send this flow's own address, `{ Psyche core Haiku }`, its title through flow as `Soft.Notice.«title»`, then its link bare, alone in a second Send, `Soft.Notice.«link»`: the watch wakes on a comment only for a link that reached the session bare, and arming it is the comment watch's work in the turn that link arrives. Then add the book to the open-books record, `/home/li/primary/flows/book/open-books.datom`, one entry per book, the first released first: `{ «title» «link» «source path» { Aspect topic Model } Watched }`, the flow that ordered it, then `Watched` or `Unwatched`.
